# DRAK Binance Trade Bot (v0.2.0)

مشروع تجريبي لبوت تحليل واختبار استراتيجيات التداول على Binance Spot. هذه النسخة مخصصة للاختبار التاريخي والمحاكاة الورقية فقط، ولا ترسل أوامر تداول حقيقية.

## حالة المشروع
- الزوج الافتراضي للاختبار: BTCUSDT.
- الإطار الأساسي: 15 دقيقة، مع تصفية إضافية من إطار الساعة.
- رأس المال الافتراضي في الإعدادات: 11 USDT.
- يعتمد جلب البيانات على واجهة Binance العامة، ولا يحتاج مفتاح API لجلب الشموع العامة.
- الاختبارات البرمجية السابقة: 8 اختبارات ناجحة.
- لم يكتمل اختبار تاريخي فعلي لمدة 90 يومًا لأن بيئة التشغيل لم تتمكن من حل اسم نطاق Binance؛ لذلك لا توجد نتائج ربح أو تراجع موثقة بعد.

## محتويات الحزمة
الحزمة المستقلة التي أُنشئت للمشروع تتضمن:
- `main.py` — نقطة التشغيل.
- `drakbot/api.py` — الاتصال بواجهة السوق العامة.
- `drakbot/strategy.py` — منطق الاستراتيجية.
- `drakbot/indicators.py` — المؤشرات.
- `drakbot/backtest.py` و`drakbot/engine.py` — الاختبار والمحرك.
- `drakbot/config.py` و`drakbot/state.py` — الإعدادات والحالة.
- `drakbot/cli.py` — أوامر التشغيل.
- `tests/` — اختبارات المؤشرات والاختبار التاريخي.
- `requirements.txt` و`.env.example` — المتطلبات ومثال الإعدادات.
- `README_AR.md` داخل الحزمة — دليل التشغيل العربي.

## تشغيل محلي
بعد الحصول على ملفات الحزمة وفك ضغطها، من داخل مجلد المشروع:
```bash
pip install -r requirements.txt
python -m pytest -q
python main.py backtest --symbol BTCUSDT --days 90
```

يحتاج الأمر الأخير إلى اتصال إنترنت للوصول إلى Binance. إذا تعذّر الاتصال، فلن يكون هناك اختبار تاريخي فعلي.

## إدارة المخاطر
لا تستخدم مفاتيح تداول أو أموالًا حقيقية في هذه النسخة. نتائج الاختبار، إن توفرت، ليست ضمانًا للأداء المستقبلي. راجع الرسوم والانزلاق السعري وأقصى تراجع وعدد الصفقات قبل أي قرار.

## فصل المشاريع
هذا المجلد خاص ببوت التداول التجريبي، وليس تطبيق `مرصد العملات / Market Observatory` الموجود في بقية المستودع.
