# DRAK Binance Trade Bot (v0.2.0)

مشروع تجريبي لبوت تحليل واختبار استراتيجيات التداول على Binance Spot. هذه النسخة مخصصة للاختبار التاريخي والمحاكاة الورقية فقط، ولا ترسل أوامر تداول حقيقية.

نسخة Python تجريبية جديدة مبنية على المواصفات المتاحة، لا تدّعي أنها استعادة لملفات أو استراتيجية سابقة. يحتوي المجلد على المصدر والاختبارات وتعليمات عربية. لا يتصل بحساب خاص ولا يرسل أوامر تداول.

## الملفات والتشغيل

- `main.py`: نقطة التشغيل.
- `drakbot/`: اتصال قراءة فقط ببيانات Binance العامة، المؤشرات، الإعدادات، الإشارات ومحرك الاختبار.
- `tests/`: اختبارات المؤشرات والمحاكاة والسلامة.
- `requirements.txt`: متطلبات التشغيل والاختبار.
- [دليل التشغيل والافتراضات بالعربية](README_AR.md).
- [تنزيل حزمة DRAK_Binance_Bot_v0.2.0.zip](DRAK_Binance_Bot_v0.2.0.zip).
- [تقرير BTCUSDT الفعلي لمدة 90 يومًا](reports/BTCUSDT_90d_backtest.md) ونسخة JSON.
- `data/BTCUSDT_15m_90d.csv`: لقطة الشموع العامة المستخدمة، تشمل 21 يومًا لتهيئة المؤشرات.

في نتيجة 2026-10-29، انخفض الرصيد الافتراضي في نافذة الاختبار خارج العينة من 11 إلى 10.398457 USDT (-5.4686%) عبر 12 صفقة. النتيجة سلبية وليست إثباتًا لربح مستقبلي؛ التفاصيل والافتراضات في التقرير.

```bash
python -m pip install -r requirements.txt
python -m pytest -q
python main.py backtest --symbol BTCUSDT --days 90 --save-data data/BTCUSDT_15m_90d.csv
```

أو أعد الاختبار من CSV محفوظ دون اتصال:

```bash
python main.py backtest --symbol BTCUSDT --days 90 --data-csv data/BTCUSDT_15m_90d.csv
```

المنطق التفصيلي للدخول والخروج افتراضي ومحافظ ومعلن في الدليل. أي نتيجة تاريخية تصف البيانات المختبرة فقط ولا تثبت الربحية المستقبلية. إذا لم تتصل البيئة بـBinance، لا تُسجل أرقام بديلة أو مفترضة.

## فصل المشاريع
هذا المجلد خاص ببوت التداول التجريبي، وليس تطبيق `مرصد العملات / Market Observatory` الموجود في بقية المستودع.
