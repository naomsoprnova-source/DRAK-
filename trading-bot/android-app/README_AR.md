# DRAK 0.3.0 — مختبر بيانات السوق والمحاكاة الورقية

يستخدم المشروع تطبيق DRAK Android الحالي كأساس، ويحوّله إلى مختبر عربي لتحليل بيانات Binance Spot العامة واختبار أفكار التداول **ورقيًا فقط**. لا يطلب مفتاح API أو حسابًا، ولا يرسل أوامر شراء أو بيع، ولا يضمن ربحًا.

## ما يقدمه

- أسعار Spot عامة لـ **BTCUSDT وETHUSDT وSOLUSDT** عبر اتصال HTTPS للقراءة فقط؛ يمكن توسيع القائمة بتحديث قائمة الرموز في محرك JavaScript والجسر الأصلي وقوائم الواجهة معًا.
- تحديث يدوي وزمني كل 60 ثانية، مع شارة اتصال ووقت آخر تحديث. عند انقطاع الشبكة تظهر حالة غير متصل/بيانات قديمة؛ لا يرجع التطبيق إلى أسعار اصطناعية.
- رسم وتحليل باستخدام شموع Binance التي أُغلقت فقط وفق وقت الخادم. الشمعة التي ما زالت تتكون مستبعدة.
- الاستراتيجيات التعليمية السبع الموجودة: المرصد المركب، تقاطع المتوسطات، ارتداد RSI، MACD، بولينجر، الاختراق، واتباع الاتجاه.
- محفظة افتراضية تبدأ من **11 USDT**، ورأس مال قابل للتغيير، ومبلغ مركز حتى منزلتين عشريتين. تُحترم حدود الرصيد والمخاطرة وتُحسب رسوم الدخول والخروج والانزلاق التقديري.
- سجل ورقي محلي، ووقف/هدف افتراضي يُراجع عند تحديث السعر أثناء بقاء التطبيق مفتوحًا، وتنبيهات صوت/اهتزاز واحتفال اختياري عند ربح مغلق.
- اختبار تاريخي من شموع Binance الفعلية، مرتب زمنيًا إلى 70% للتطوير و30% للتقييم. الدخول بعد إشارة الشمعة المغلقة يكون على افتتاح الشمعة التالية؛ تستخدم مؤشرات التقييم الشموع السابقة للتهيئة فقط. يعرض صافي الربح والخسارة، ونسبة الفوز، والتراجع الأقصى، وعدد الصفقات والرسوم والانزلاق.

نتائج الاختبار تصف الفترة المختارة فقط، وقد تكون العينة صغيرة أو تختلف عن التنفيذ الواقعي. الرسوم والانزلاق تقديرات، ووقف/هدف المحاكاة ليسا أوامر منصة ولا يعملان إذا كان التطبيق مغلقًا أو انقطع الاتصال.

## مصادر البيانات والأمان

تستخدم طبقة Android عنوان Binance العام `data-api.binance.vision` لواجهات [الوقت](https://developers.binance.com/docs/binance-spot-api-docs/rest-api/general-endpoints)، و[الأسعار والشموع](https://developers.binance.com/docs/binance-spot-api-docs/rest-api/market-data-endpoints). الواجهة داخل WebView لا تفتح اتصالًا شبكيًا مباشرًا؛ يسمح جسر Kotlin المحلي بطلبات HTTPS محددة وGET فقط. راجع [سياسة الأمان والخصوصية](SECURITY_AR.md).

لا تضمن الاستراتيجيات أو الاختبارات أي نتيجة مستقبلية. لا توجد أموال حقيقية أو حساب منصة أو مفاتيح أسرار في هذا الإصدار.
