# DRAK Android — تطبيق تجريبي فقط

تطبيق أندرويد تعليمي وتجريبي لمحاكاة متابعة السوق والاستراتيجيات باستخدام محفظة افتراضية محلية. لا ينفذ التطبيق تداولًا حقيقيًا، ولا يتصل بحساب تداول أو Testnet، ولا يطلب مفاتيح API أو كلمات مرور. أسعار السوق العامة اختيارية؛ ويمكن استخدام المحفظة التجريبية حتى عند عدم توفر الأسعار أو الاتصال.

## نطاق التطبيق

- المحفظة والأرصدة والصفقات وسجل النشاط محاكاة محلية على الجهاز، وليست أصولًا أو معاملات لدى منصة تداول.
- عند توفر اتصال، يمكن جلب أسعار Spot وبيانات الشموع (klines) العامة من Binance. لا يتطلب ذلك تسجيل دخول أو مفتاح API.
- عند غياب الاتصال أو تعذر جلب الأسعار، تظل تجربة المحفظة التجريبية المحلية ممكنة؛ وقد لا تتوفر تحديثات أسعار السوق.
- لا يوجد وضع حي أو وضع Testnet، ولا ربط بحساب، ولا إرسال أوامر شراء أو بيع حقيقية.
- نتائج الاستراتيجيات والاختبارات التاريخية تعليمية ومحاكاة، ولا تضمن الربح أو تمثل توصية استثمارية.

## كتالوج الاستراتيجيات

يدعم التطبيق كتالوجًا قابلًا للتوسعة لاستراتيجيات ومؤشرات شائعة، وقد يشمل: الشراء والاحتفاظ (buy-and-hold)، ومتوسط التكلفة الدوري (DCA)، والشبكة (grid)، وتقاطع المتوسطات المتحركة وEMA، وRSI، وMACD، والارتداد إلى المتوسط باستخدام Bollinger Bands، والاختراق (breakout)، واتباع الاتجاه، والزخم، وStochastic، وVWAP، وATR، ومستويات Fibonacci، وIchimoku، وغيرها.

هذه أمثلة على كتالوج قابل للإضافة والتغيير، وليست ادعاءً بحصر كل استراتيجية منشورة. وجود استراتيجية أو مؤشر لا يثبت فعاليته ولا يضمن ربحية نتائجه.

## البناء والتحقق

يتطلب البناء Java 17 أو أحدث واتصالًا بالإنترنت لتنزيل Gradle ومكتبات Android. من مجلد `android-app`:

    gradle assembleDebug

مسار APK المتوقع:

    app/build/outputs/apk/debug/app-debug.apk

في هذا التحديث نجح بناء debug باستخدام `assembleDebug testDebugUnitTest`، واجتازت اختبارات المحاكاة المحلية 11/11. لم يُثبّت التطبيق ولم يُختبر على هاتف Android فعلي؛ راجع [حالة المشروع](PROJECT_STATUS_AR.md) و[قائمة الاختبار](TEST_CHECKLIST_AR.md).

## حدود مهمة

1. كل الأموال والأرصدة والمحافظ والصفقات والسجلات داخل التطبيق افتراضية ومحلية، ولا تمثل رصيدًا لدى Binance أو أي جهة أخرى.
2. أسعار Binance المشار إليها بيانات سوق عامة فقط عند توفر اتصال؛ لا توجد مصادقة لحسابات ولا بيانات رصيد خاصة.
3. لا تدخل مفاتيح API أو كلمات مرور أو بيانات حساب في التطبيق أو المستودع. التطبيق لا يحتاجها.
4. لا يتصل التطبيق بـTestnet أو بحساب حي، ولا يرسل أوامر تداول حقيقية، ولا يتيح نمطًا حيًا.
5. قد تكون الأسعار أو بيانات الشموع غير متاحة أو متأخرة عند انقطاع الاتصال. يظل وضع المحفظة التجريبية المحلية قابلًا للاستخدام دون أسعار.
6. النتائج المحاكاة لا تعكس بالضرورة السيولة أو الانزلاق أو الرسوم أو ظروف التنفيذ الفعلية، ولا تضمن أداءً مستقبليًا.
7. نجاح البناء والاختبارات الآلية لا يثبت تجربة المستخدم على جهاز فعلي أو صلاحية أي استراتيجية.
