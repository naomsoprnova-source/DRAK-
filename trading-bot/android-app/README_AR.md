# DRAK Android — الإصدار 0.1.0

نسخة أندرويد أولية تربط واجهة عربية بتداول Binance Spot عبر API. تتضمن اختيار الاستراتيجية، قراءة أسعار عامة، فحصًا تاريخيًا مبسطًا، ومراقبة آلية أثناء بقاء التطبيق مفتوحًا.

## ما الذي يعمل في هذا الإصدار؟

- اتصال تجريبي عبر Binance Spot Testnet، أو اتصال مباشر عند اختيار المستخدم ذلك.
- واجهة عربية داكنة، قائمة من 7 استراتيجيات فنية، رسم سعري، مؤثرات صوتية واحتفال قصاصات عند نتائج التداول الإيجابية.
- قراءة الرصيد والأصول من الحساب الذي تم ربطه.
- شراء سوقي بميزانية محددة من 5 إلى 10 USDT، وبيع سوقي لكمية يحددها سجل الصفقة المحلية.
- مفاتيح API محفوظة بتشفير AES-GCM باستخدام Android Keystore، ولا تُحفظ في `localStorage` الخاص بواجهة التطبيق.
- اختبار تاريخي مبسط على الشموع المحمّلة مع رسوم وانزلاق تقديريين.
- إجراء بناء آلي لإنتاج APK تجريبي عبر GitHub Actions.

## حدود مهمة

1. هذه نسخة أولية وليست خدمة تداول احترافية مختبرة على أموال حقيقية. يلزم إكمال بناء APK وتشغيل قائمة اختبارات يدوية قبل اعتمادها.
2. التداول الآلي في هذا الإصدار يعمل ما دام التطبيق مفتوحًا. قد يتوقف عند إغلاق التطبيق أو إنهائه من نظام أندرويد؛ لا تعتبره بوتًا يعمل 24/7.
3. سجل الصفقة وبعض الإحصاءات محفوظة محليًا لأغراض الواجهة؛ لا تعتمد عليها بديلًا عن سجل المنصة، خصوصًا بعد حذف بيانات التطبيق أو إعادة تثبيته.
4. اختبارات الربحية المبسطة لا تحاكي كامل عمق دفتر الأوامر، ولا التنفيذ الجزئي، ولا جميع مرشحات أزواج التداول، ولا رسوم حسابك الدقيقة. النتائج السابقة لا تضمن المستقبل.
5. الحد الأقصى المبرمج لقيمة أمر الشراء 10 USDT، لكن قواعد المنصة والزوج والرصيد المتاح قد ترفض الأمر. لا تستخدم هذا الحد كإشارة إلى أن الاستثمار آمن.
6. لا يوجد دعم للهامش أو العقود الآجلة أو الرافعة أو السحب. لا تضف صلاحية السحب إلى مفتاح API.
7. مفاتيح API لا يمكن ضمان حمايتها إذا كان الجهاز مخترقًا أو معدلًا أو مصابًا ببرمجيات خبيثة. يفضّل استخدام مفتاح مخصص للتداول، وصلاحيات محدودة، وتقييد IP متى أمكن. اتصال الهاتف المباشر قد يتأثر بتغير عنوان IP.
8. لا تُفعّل التداول الحقيقي إلا بعد اختبار شبكة الاختبار والتحقق من أذونات المفتاح. عند اختيار الوضع الحقيقي، يطلب التطبيق كتابة `تداول حقيقي` وتأكيد المخاطر؛ هذا لا يجعل الاستراتيجية رابحة ولا يمنع كل خطأ.

## البناء

يفترض البناء وجود Java 17 واتصال بالإنترنت لتنزيل إضافات Gradle ومكتبات أندرويد.

من مجلد `android-app`:

```bash
gradle assembleDebug
```

سيكون الناتج عادةً في:

```text
app/build/outputs/apk/debug/app-debug.apk
```

أو ادفع التغييرات إلى GitHub وافتح تبويب Actions؛ سير العمل `Build DRAK Android APK` يبني التطبيق ويرفع `app-debug.apk` كأثر قابل للتنزيل إذا نجح البناء.

## إعداد Binance

- ابدأ ببيئة Spot Testnet ومفاتيحها المخصصة للاختبار.
- للتداول الحقيقي، أنشئ مفتاح API من المنصة بنفسك، وفعّل Spot Trading فقط، وعطّل السحب والتحويلات، ولا تشارك المفتاح السري مع أي شخص.
- لا تستخدم مفاتيح API الخاصة بحسابك الحقيقي في اختبارات أو صور أو مستودع GitHub.
- توثيق Binance الرسمي: https://developers.binance.com/en/docs/products/spot/rest-api
