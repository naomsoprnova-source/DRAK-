# معمارية DRAK Paper

## اختيار الطبقات

- **غلاف Android:** Kotlin Activity واحدة وWebView محلي، استمرارية توافقية مع المشروع الحالي دون إدخال إطار أو اعتماد مدفوع.
- **واجهة:** HTML/CSS/JavaScript محلي في `app/src/main/assets/`، مقسمة إلى `index.html`, `styles.css`, `paper-engine.js`, `app.js`.
- **الحالة:** تخزين إعدادات ومراكز ورقية فقط في `localStorage`; إعادة الضبط تمسح بيانات المحاكاة. لا توجد قاعدة بيانات، حساب مستخدم، مزامنة، أو Backend.
- **الشبكة:** لا إذن `INTERNET`، لا WebView bridge، لا `fetch`/XHR، لا HTTP client، وCSP بـ`connect-src 'none'`.
- **البيانات:** مولد محلي حتمي لشموع اصطناعية تتبدل حسب الرمز/الفاصل؛ يضاف دائمًا وصف «مصطنع» قرب السعر والرسم والاختبار.

## الملفات والمسؤولية

| ملف | مسؤولية |
| --- | --- |
| `MainActivity.kt` | تحميل الأصول المحلية، إعداد WebView مقيد، تنظيفه عند الإغلاق |
| `AndroidManifest.xml` | تعريف Activity بلا INTERNET أو VIBRATE |
| `index.html` | بنية عربية دلالية وتنقل الشاشات |
| `styles.css` | الرموز والاستجابة والمكونات والتباين |
| `paper-engine.js` | مولد الشموع والمؤشرات والإشارات والمحاسبة الورقية والاختبار |
| `app.js` | ربط الأحداث والعرض والتخزين المحلي، دون دوال شبكة |

## تدفق F03 الرأسي

إعداد افتراضي → بيانات اصطناعية ثابتة قابلة للتكرار → اختيار مبلغ لا يتجاوز السقف أو النقد → حساب رسوم/انزلاق ورقيين → إنشاء PaperPosition محلي → إغلاق يدوي عند السعر الاصطناعي → تحديث الرصيد والسجل. كل عملية واضحة أنها افتراضية، ولا يمكن الوصول إلى طبقة مالية حقيقية.

## قيود البيانات والمخاطر

كل الأسعار والسجلات في هذه النسخة تعليمية؛ لا يوجد حساب أو رصيد منصة. يستخدم مبلغ افتراضي موجب، ويُرفض فتح مركز إذا كان موجودًا بالفعل أو إذا تجاوزت القيمة النقد أو السقف. نتيجة الاختبار اصطناعية ولا تُعرض كتوصية أو ضمان ربح.
