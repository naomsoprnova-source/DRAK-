# خطة اختبار DRAK 0.3.0

## حدود السوق والمحاكاة

| الجزء | اختبار النجاح | حالة خطأ/حد |
| --- | --- | --- |
| مصدر Binance | وقت وأسعار وKlines عامة من مضيف HTTPS ثابت | لا أسعار بديلة عند offline أو فشل الطلب |
| تطبيع Klines | رمز وفاصل وتوقيت UTC وOHLCV متسق | استبعاد الشمعة المفتوحة ورفض بيانات معطوبة أو غير Binance |
| الجسر | callback ناجح، timeout، HTTP error وRetry metadata | لا XHR/fetch/WebSocket أو endpoint أوامر |
| تحديث السوق | يدوي وكل دقيقة مع حالة ووقت | الطلب القديم لا يستبدل رمزًا/فاصلًا تم اختياره حديثًا |
| الاستراتيجيات | السبع تقرأ الشموع المغلقة | رمز مجهول أو بيانات قليلة لا ينتج إجراء |
| باكتيست | بيانات متصلة وتقسيم 70/30 ودخول بالشمعة التالية | رفض النقص والفجوات؛ لا بيانات مستقبل في تطوير الماضي |
| المحاسبة الورقية | رصيد 11 USDT ومبلغ عشري ورسوم وانزلاق | رفض مصدر/رصيد/مبلغ/مخاطرة غير صالحة |
| التخزين والترقية | سجل ورقي محلي واستعادة آمنة | حذف بيانات الإصدار الاصطناعي القديم ورفض prototype/state غير المتسق |
| Android | بناء APK وفحص الأذونات والتوقيع | تثبيت/تشغيل Android 9 يتطلب جهازًا أو محاكيًا متاحًا |

## نتائج نُفذت

- اختبارات Node: 12/12، للمحرك والجسر والشموع المغلقة وسبع الاستراتيجيات والمبلغ العشري والرسوم والمخاطر ومنع تسرب المستقبل وأخطاء الطلب.
- اختبارات Python الثابتة: 14/14 لحدود WebView والجسر والManifest وغياب مفاتيح وأوامر التداول.
- اختبارات DRAK الكاملة عبر `pytest -q`: 87/87.
- اختبار Playwright: 10/10، ببيانات Binance عامة ملتقطة وجسر Android محلي محاكى. شمل التحديث وتبديل BTC/ETH وقراءة الاستراتيجيات وفتح/إغلاق 3.50 USDT وباكتيست 7 أيام ومقارنة الاستراتيجيات السبع ومحاكاة انقطاع الشبكة دون توليد سعر بديل. لم تسجل وحدة التحكم أخطاء، وظهرت موارد loopback المحلية فقط.
- قياس أفقي مباشر في Playwright: 360 و390 و720px؛ `scrollWidth` للوثيقة يساوي عرض المنفذ في المقاسات الثلاثة.
- اختبار Binance عام منفصل في بيئة البناء: أسعار BTC/ETH/SOL و349 شمعة BTCUSDT مغلقة بفاصل ساعة، مع تمرير البيانات الحقيقية للمؤشرات والباكتيست ومقارنة الاستراتيجيات السبع. تفاصيل العينة في تقرير الاختبارات.
- بناء APK نظيف وفحص AAPT و`apksigner`; لا يوجد اختبار تثبيت أو تشغيل فعلي على Android 9.

التفاصيل الدقيقة للبناء والنتائج والمراجع في [تقرير الاختبارات](test-report.md). النتائج التاريخية ليست ضمانًا أو توصية.
