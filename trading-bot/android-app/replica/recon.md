# خريطة DRAK — الانتقال إلى الإصدار 0.3.0

## سياق إعادة البناء

هذا المشروع هو تطبيق Android العربي الحالي `trading-bot/android-app`، وليس تطبيقًا منفصلًا. بُني الإصدار 0.2.0 كتجربة محاكاة غير متصلة، ثم تغيّر النطاق بموافقة مالك المشروع في 6 نوفمبر 2026: أصبح الهدف تحليل بيانات Binance Spot العامة الحقيقية مع بقاء الصفقات ورقية فقط. لا تُنسخ شيفرة أو شعارات أو نصوص أو أصول من تطبيق آخر؛ تصميم DRAK ومحتواه أصليان.

## نطاق 0.3.0

- قراءة أسعار وKlines العامة عبر HTTPS بلا API key.
- دعم BTCUSDT وETHUSDT وSOLUSDT، والتحليل من شموع مغلقة فقط.
- الحفاظ على المحفظة الورقية والواجهة العربية والاستراتيجيات السبع والسجل.
- جلب تاريخ فعلي واختباره زمنيًا 70/30 مع منع استعمال المستقبل قبل التنفيذ.
- استبعاد مفاتيح الحساب الخاص، الرصيد الخاص، الأوامر الحقيقية، وميزات الخلفية.

## تدفق الاستخدام

1. فتح التطبيق وقراءة الوقت وسعر السوق وKlines من Binance.
2. حذف أي شمعة يكون `closeTime >= serverTime` والتحقق من الترتيب وOHLCV.
3. عرض حالة الاتصال والوقت ومصدر السعر؛ لا يُملأ فراغ البيانات بسعر اصطناعي.
4. اختيار استراتيجية وتحليل آخر إغلاق؛ لا يوجد إرسال لأمر.
5. إدخال مبلغ ورقي ضمن النقد وحد المخاطرة؛ خصم الرسوم والانزلاق التقديريين محليًا.
6. عند الإغلاق اليدوي أو شرط وقف/هدف أثناء تحديث التطبيق، إضافة النتيجة والسعر والرسوم إلى السجل المحلي.
7. اختبار تاريخ Binance متصل زمنيًا؛ تقسيم 70%/30%، وإشارة عند إغلاق، وتنفيذ افتراضي عند افتتاح الشمعة التالية.

## مصدر خارجي غير مسموح

لا توجد مرجعية تطبيق منافس ولا نُقلت أصول منه. مصدر السوق هو API Binance العام الموثق أعلاه فقط. لا تستخدم أسرار أو حسابات أو خدمات مدفوعة.
