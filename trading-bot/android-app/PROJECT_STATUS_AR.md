# حالة مشروع DRAK Android — 0.2.0

آخر تحديث: 6 نوفمبر 2026.

## النتيجة

أعيد بناء التطبيق كتجربة عربية مستقلة ومحاكاة محلية فقط. تتضمن الواجهة خمس شاشات للملخص والتحليل والمراكز الورقية والسجل والإعدادات. الأسعار مولدة اصطناعيًا؛ لا حسابات أو مفاتيح أو طلبات شبكة أو أوامر تداول. أزيلت واجهات الاتصال القديمة، ويُمسح سجل الواجهة المحلي القديم عند بدء النسخة الجديدة، مع محاولة حذف مخزن المفاتيح القديم من Android Keystore.

## البناء وملف APK

- `gradle clean assembleDebug`: **نجح**.
- APK: `app/build/outputs/apk/debug/app-debug.apk`، الحجم 841,654 بايت (نحو 822 KiB).
- الحزمة `com.drak.marketbot`، versionCode `2`، versionName `0.2.0`.
- `minSdk 26` (Android 8.0+) و`targetSdk 28`، مع compile SDK 35.
- `aapt dump permissions`: لا توجد أذونات معلنة. `apksigner verify`: توقيع debug v2 صالح.
- SHA-256: `9550dd452cddd04a95c031771c7eb659034a18dc6a6554fa529b722389653c87`.
- ظهرت تحذيرات غير مانعة من Android SDK حول XML v4 ومن Kotlin عن واجهات Android قديمة؛ لم تمنع إنشاء APK.

ملف debug تجريبي وليس إصدارًا release موقّعًا للنشر في متجر. لم يُختبر التثبيت أو الإقلاع على هاتف فعلي: `adb` غير متوفر ولا يوجد جهاز أو محاكي متصل في بيئة البناء. يلزم تثبيت تجريبي على Android 8+ قبل وصف التطبيق بأنه مجرّب على الهاتف. `targetSdk 28` يحتاج مراجعة/ترقية قبل أي نشر رسمي في متجر حديث.
