# حالة مشروع DRAK Android — تطبيق تجريبي

آخر تحديث: 29 أكتوبر 2026.

## النطاق الحالي

- تطبيق Android تجريبي لمحاكاة المحفظة والاستراتيجيات.
- الأموال الافتراضية والمحافظ والأرصدة والصفقات والسجل محاكاة محلية على الجهاز.
- أسعار السوق العامة وبيانات الشموع (klines) من Binance Spot اختيارية عند توفر الاتصال، ولا تتطلب مفاتيح API.
- يمكن استعمال المحفظة التجريبية المحلية دون اتصال أو دون أسعار محدثة.
- لا توجد مفاتيح API أو بيانات حساب، ولا اتصال بـTestnet أو حساب حي، ولا أوامر تداول حقيقية أو وضع حي.
- كتالوج الاستراتيجيات قابل للتوسعة ولا يدعي شمول جميع الاستراتيجيات المنشورة أو ضمان الربحية.

## البناء والاختبار

- نجح بناء Android debug عبر `assembleDebug testDebugUnitTest` باستخدام Gradle 8.9 وAndroid SDK API 35.
- اجتازت اختبارات المحاكاة المحلية عبر Node.js: 11 اختبارًا ناجحًا، 0 فاشلة.
- مسار APK في بيئة البناء: `app/build/outputs/apk/debug/app-debug.apk`.
- حجم APK نحو 826 كيلوبايت؛ SHA-256: `620b0c69c4f68bc056eb43890b2d70db9e826c50949de6eb4abd82ec1288b508`.
- هذا بناء debug، وليس إصدارًا نهائيًا موقّعًا للنشر.
- لم يُثبّت التطبيق ولم يُختبر على جهاز Android فعلي.
- لم يُتحقق يدويًا من الاتصال الحي بمصدر الأسعار؛ البناء الناجح لا يثبت أن الاتصال متاح في كل منطقة أو جهاز.

## ما لم يكتمل التحقق منه

1. لم يُختبر التطبيق على جهاز Android فعلي.
2. يلزم تنفيذ اختبار يدوي لتدفق المحفظة والأوامر المحاكية وحالات انقطاع الاتصال.
3. لم يُتحقق يدويًا من توافر أسعار السوق العامة عبر الأجهزة أو الشبكات المختلفة.
4. لا توجد أدلة تبرر ادعاءات ربحية أو فعالية مستقبلية لأي استراتيجية.

جميع القيم والصفقات والسجلات في التطبيق تجريبية ومحلية، وليست أموالًا أو معاملات لدى منصة تداول.
