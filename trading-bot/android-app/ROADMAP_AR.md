# خارطة طريق DRAK ورقي

## الإصدار الحالي 0.2.0

واجهة عربية أعيد بناؤها كتجربة ورقية محلية: شموع اصطناعية، تحليل سبع استراتيجيات، محاسبة مركز افتراضي، سجل محلي، واختبار تعليمي 70/30. لا توجد حسابات أو مفاتيح أو اتصال إنترنت أو تنفيذ أوامر.

## تحسينات مناسبة لاحقًا

تحسين قابلية الوصول على أحجام وأحجام خط مختلفة، إضافة سيناريوهات اصطناعية للتذبذب والاتجاه الجانبي، شرح المؤشرات بلغة أبسط، وزيادة تغطية اختبارات المحرك وحالات الاستعادة المحلية. أي توسيع للبيانات يبقى مولدًا محليًا ما دام نطاق المشروع محاكاة فقط.

## خارج النطاق

لا توجد خطة في هذا الإصدار لربط منصة أو حساب تداول أو مفتاح API أو جلب سعر حي أو إرسال أوامر أو تشغيل بوت بالخلفية. أي تغيير لهذا النطاق يحتاج قرارًا جديدًا من مالك المشروع ومراجعة منفصلة؛ لا تضيفه كتحسين تلقائي.
