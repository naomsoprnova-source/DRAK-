# خارطة طريق DRAK Android

هذه خارطة تطوير مقترحة، وليست ادعاءً بأن البنود المستقبلية موجودة بالفعل.

## المرحلة 0.1.0 — نسخة أولية

- واجهة عربية داكنة.
- قائمة استراتيجيات تعليمية.
- بيانات سوق عامة واختبار تاريخي مبسط.
- إعداد اتصال Spot API ووضع اختبار.
- مؤثرات صوتية وقصاصات احتفالية.
- بناء APK تجريبي عبر GitHub Actions.

## المرحلة التالية — الاختبار والثبات

- تنفيذ قائمة الاختبار اليدوي على جهاز حقيقي.
- التحقق من الاستراتيجيات السبع ومقارنة النتائج يدويًا مع بيانات السوق.
- اختبار رفض الأوامر، وانقطاع الشبكة، وتغير الرصيد، وفشل الاتصال.
- إظهار سجل واضح لكل إشارة وأمر وسبب الرفض.
- إضافة حدود يومية للصفقات والخسارة، وإيقاف طارئ واضح.
- تحسين إمكانية الوصول وإتاحة إيقاف المؤثرات بالكامل.

## مرحلة لاحقة — تشغيل أكثر موثوقية

- دراسة تشغيل المراقبة المستمرة باستخدام Android foreground service وإشعار دائم، مع احترام قيود البطارية والنظام.
- عدم تنفيذ تداول في الخلفية قبل اختبار الاستعادة بعد إعادة تشغيل التطبيق وانقطاع الشبكة.
- توثيق رسوم المنصة وحدود الأزواج والحد الأدنى للأوامر بدقة.
- اختبارات آلية لتوقيع الطلبات وحماية الأسرار وسلوك الأخطاء.
- توفير نسخة إصدار موقعة بمفتاح إصدار محفوظ خارج GitHub، مع التحقق من بصمة الملف.

## شروط قبول التداول الحقيقي

لا يُعد الإصدار جاهزًا للتداول الحقيقي إلا بعد اجتياز الاختبارات اليدوية والآلية، والتحقق من سلوك الأوامر والأرصدة والرسوم، ومراجعة حماية المفاتيح، وإظهار حدود المخاطر للمستخدم. النجاح في بناء APK وحده لا يحقق هذه الشروط.
