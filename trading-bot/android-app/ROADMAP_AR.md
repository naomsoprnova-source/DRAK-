# خارطة طريق DRAK ورقي

## الإصدار الحالي 0.3.0

مختبر Android عربي يقرأ أسعار وبيانات Binance Spot العامة عبر HTTPS للقراءة فقط، ويحلل الشموع المغلقة ويعرض سبع استراتيجيات واختبارًا تاريخيًا 70/30 ومحاسبة ورقية. يبدأ الرصيد الافتراضي من 11 USDT وتُقدّر الرسوم والانزلاق. لا حساب أو مفتاح API أو أمر تداول حقيقي.

## تحسينات لاحقة مناسبة

- توسيع أسواق Spot بعد مراجعة السماح بالرمز في واجهة المحرك والجسر والواجهة معًا.
- تجربة تثبيت واستخدام على جهاز Android 9 فعلي، ثم مراجعة التوافق على الإصدارات الأقدم ضمن `minSdk`.
- تحسين شرح المخاطر ورسم المؤشرات وزيادة اختبارات انقطاع الشبكة وتغيّر حدود Binance.
- مراجعة مستمرة لتوافق API العامة وسياسة WebView وإتاحة الوصول والأداء على الأجهزة محدودة الموارد.

## خارج النطاق

لا يضاف تداول حقيقي أو حساب منصة أو API Key أو سحب/تحويل أو تشغيل صفقات بالخلفية. أي تغيير في هذه الحدود يحتاج قرارًا جديدًا ومراجعة أمان واختبارات منفصلة.
