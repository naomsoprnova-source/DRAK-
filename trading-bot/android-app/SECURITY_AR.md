# الأمان والخصوصية — DRAK Android

## طبيعة التطبيق

DRAK Android تطبيق تجريبي فقط. الأرصدة والمحافظ والصفقات وسجل النشاط محاكاة محلية على الجهاز، ولا تمثل أموالًا أو معاملات حقيقية. لا يتصل التطبيق بحساب تداول أو Binance Testnet أو وضع حي، ولا ينفذ أوامر تداول حقيقية.

## مفاتيح API وبيانات الحساب

- لا يحتاج التطبيق إلى مفاتيح API أو كلمات مرور أو بيانات دخول.
- لا تُدخل هذه البيانات في التطبيق، ولا تضفها إلى ملفات المصدر أو الصور أو السجلات أو المستودع.
- عند توفر اتصال بالإنترنت، قد تُطلب أسعار Spot وبيانات الشموع العامة فقط؛ لا يتطلب ذلك مصادقة.
- لا توجد قراءة لأرصدة منصة أو إرسال أوامر إليها. الأرصدة والصفقات المعروضة افتراضية ومحلية.

## الاتصال والبيانات

مصدر أسعار السوق العامة الاختياري هو Binance Spot العام (الأسعار وبيانات klines) عند الاتصال. إذا تعذر الاتصال، يمكن استخدام المحفظة التجريبية المحلية دون أسعار محدثة. بيانات السوق العامة ليست بيانات حساب، وقد تتأخر أو تنقطع.

## حدود الاستخدام

نتائج المحاكاة والاختبار التاريخي لأغراض تعليمية فقط. قد لا تشمل الرسوم أو السيولة أو الانزلاق أو سائر ظروف السوق، ولا تضمن ربحًا أو نتيجة مستقبلية. لا تستخدم هذه النتائج لاتخاذ قرار استثماري باعتبارها نصيحة مالية.

## قائمة تحقق للخصوصية والأمان

1. تأكد من عدم إدخال مفاتيح API أو كلمات مرور؛ لا توجد حاجة إليها.
2. تحقق من أن استخدام التطبيق يظل ممكنًا في المحفظة التجريبية عند تعطيل الاتصال، مع توقع غياب أسعار السوق الحديثة.
3. تعامل مع الصفقات والسجلات والأرصدة باعتبارها بيانات محاكاة محلية، لا سجلًا ماليًا موثوقًا أو سجلًا لمنصة.
4. لا تنشر سجلات أو لقطات شاشة قبل مراجعتها وإزالة أي معلومات شخصية قد تتضمنها.
5. لم يُجرَ حتى الآن اختبار على جهاز Android فعلي؛ يلزم إجراء الاختبارات قبل وصف سلوك الجهاز بأنه متحقق.
