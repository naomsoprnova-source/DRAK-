# الأمان والخصوصية — DRAK Android

## مفاتيح API

- لا تضع مفاتيح API أو الأسرار أو كلمات المرور داخل ملفات المصدر أو الصور أو المستودع.
- أنشئ مفتاحًا مخصصًا للتطبيق من منصة Binance بنفسك.
- ابدأ بمفاتيح Spot Testnet؛ مفاتيح الاختبار تختلف عن مفاتيح الحساب الحقيقي.
- عند الانتقال للحقيقي، فعّل صلاحية Spot Trading فقط، وأوقف السحب والتحويلات وأي صلاحيات لا يحتاجها التطبيق.
- استخدم تقييد عنوان IP إن كان ذلك ممكنًا ومستقرًا في بيئتك. اتصال الهاتف قد يتغير عنوانه العام.
- إذا انكشف المفتاح، أبطله من المنصة فورًا وأنشئ مفتاحًا جديدًا.

## حدود الأمان

تخزين المفتاح مشفرًا محليًا لا يحمي جهازًا مخترقًا أو معدلًا. لا تعتمد على التطبيق باعتباره محفظة أو نظام حفظ أموال. لا تشارك سجل الشاشة إذا كان يعرض معلومات الحساب أو الأرصدة أو أي أسرار.

## مخاطر التداول

أوامر السوق قد تُنفذ بسعر مختلف عن السعر المعروض، وقد ترفضها المنصة بسبب الرصيد أو الحد الأدنى للزوج أو قيود التداول. اختبار الاستراتيجية التاريخي لا يحاكي بالضرورة جميع ظروف التنفيذ، ولا يضمن النتائج المستقبلية.

## قائمة تحقق قبل التداول الحقيقي

1. اختبار قراءة الأسعار في وضع الاختبار.
2. اختبار قراءة الأرصدة بمفتاح محدود الصلاحيات.
3. التأكد من عدم وجود صلاحية سحب.
4. اختبار حالات انقطاع الإنترنت والرفض والمهلة الزمنية.
5. مراجعة حجم الأمر والرسوم وحدود الزوج.
6. مراجعة سجل الأوامر داخل منصة Binance نفسها.
7. البدء بمبالغ صغيرة فقط بعد اكتمال الاختبارات، مع إدراك احتمال خسارة رأس المال.
