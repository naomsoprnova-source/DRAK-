# بناء وتثبيت DRAK Android

هذا الدليل لبناء نسخة تجريبية من تطبيق محاكاة محلية. البناء أو التثبيت لا يفعّل حساب تداول أو Testnet أو وضعًا حيًا، ولا يحول الصفقات الافتراضية إلى أوامر حقيقية.

## البناء من المصدر

يتطلب البناء Java 17 واتصالًا بالإنترنت لتنزيل Gradle ومكتبات Android. من مجلد `trading-bot/android-app` جرّب:

    gradle assembleDebug

إذا اكتمل البناء بنجاح، يكون مسار APK المتوقع عادةً:

    app/build/outputs/apk/debug/app-debug.apk

الأمر والمسار أعلاه تعليمات عامة فقط. لا يوجد في هذا الدليل تأكيد على نجاح build؛ تحقق من رمز الخروج وسجل البناء والملف الناتج قبل الإبلاغ عن النجاح.

## تنزيل APK من GitHub Actions

إذا توفر تشغيل ناجح حديث لسير عمل Android، يمكن فتح سجل ذلك التشغيل وتنزيل أثر APK التجريبي منه. تحقق من حالة التشغيل وتاريخ الأثر ومصدره قبل التثبيت؛ لا تفترض وجود أثر صالح أو تشغيل ناجح دون التحقق منهما.

## التثبيت على Android

1. انقل APK موثوق المصدر إلى الهاتف أو نزّله من أثر بناء تحققت منه.
2. افتحه باستخدام مدير الملفات واتبع تعليمات Android للتثبيت من ذلك المصدر عند الحاجة.
3. راجع أذونات التطبيق قبل المتابعة.
4. استخدم التطبيق كتجربة بمحفظة افتراضية محلية. لا تدخل مفاتيح API أو كلمات مرور أو بيانات حساب؛ التطبيق لا يحتاجها.

ملف `debug` مخصص للتجربة، وليس إصدارًا نهائيًا موقّعًا للنشر في متجر التطبيقات. لا يوجد اختبار على جهاز Android فعلي حتى الآن.

## الاتصال بالإنترنت

عند توفر الاتصال، يمكن للتطبيق جلب أسعار Spot وبيانات الشموع العامة من Binance دون مصادقة. عند تعذر الاتصال، يمكن استخدام المحفظة التجريبية المحلية دون أسعار سوق محدثة. لا يتصل التطبيق بحساب أو Testnet ولا يرسل أوامر تداول حقيقية.
