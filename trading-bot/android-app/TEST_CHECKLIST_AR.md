# قائمة اختبار النسخة الأولية

هذه قائمة تشغيل قبل تجربة أي تداول حقيقي:

- [ ] نجاح بناء APK من GitHub Actions دون أخطاء.
- [ ] تثبيت التطبيق على جهاز أندرويد 9 أو أحدث وفتح الواجهة العربية.
- [ ] الوصول إلى الأسعار العامة من غير إدخال مفاتيح.
- [ ] التحقق من كل استراتيجية على بيانات الشموع وعدم ظهور إشارة عندما لا تكفي البيانات.
- [ ] الاتصال بشبكة Binance Spot Testnet بمفتاح اختبار، ثم قراءة الرصيد.
- [ ] إرسال أمر شراء تجريبي صغير، والتحقق من سجل الأوامر على منصة الاختبار.
- [ ] اختبار أمر بيع تجريبي والتحقق من أن كمية البيع تتوافق مع مرشح LOT_SIZE.
- [ ] تجربة قطع الإنترنت في أثناء الطلب. عند عدم التأكد من نتيجة الأمر، يجب أن يتوقف البوت ويُراجع سجل المنصة قبل إعادة التشغيل.
- [ ] اختبار زر الإيقاف ومفتاح المؤثرات الصوتية وإيقاف/تشغيل إبقاء الشاشة مضاءة.
- [ ] اختبار كل استراتيجية في اختبار تاريخي، ثم مقارنة عيّنة النتائج بحساب مستقل.
- [ ] اختبار حدود حجم الصفقة وحد الخسارة اليومي، والتأكد من أنها توقف البوت في الحالات المتوقعة.
- [ ] التحقق من عدم وجود مفاتيح حقيقية أو بيانات اعتماد في ملفات المشروع أو السجلات.
- [ ] لا يبدأ التداول الحقيقي إلا بعد اكتمال هذه الاختبارات ومراجعة صلاحيات مفتاح API يدويًا.

هذه القائمة لم تُعلّم كمكتملة؛ يلزم تنفيذها على جهاز فعلي وحساب اختبار.
