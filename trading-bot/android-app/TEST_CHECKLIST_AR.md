# قائمة اختبار DRAK Android التجريبي

هذه القائمة تخص المحاكاة المحلية وأسعار السوق العامة فقط. لا تشمل Testnet أو حسابات تداول أو أوامر حقيقية؛ فهذه الوظائف ليست ضمن نطاق التطبيق.

## البناء والاختبار الآلي

- [x] نجاح بناء `assembleDebug testDebugUnitTest` في بيئة البناء.
- [x] اجتياز اختبارات Node.js للمحاكاة والأمان: 11 ناجحًا، 0 فاشلة.
- [ ] تثبيت التطبيق وتشغيله على جهاز Android فعلي وتوثيق طراز الجهاز وإصدار النظام والنتيجة.

## المحفظة التجريبية المحلية

- [ ] التحقق يدويًا من أن الأرصدة والمحافظ المعروضة افتراضية ومحلية وليست أرصدة منصة.
- [ ] تجربة إنشاء/تحديث صفقة محاكاة والتأكد من ظهورها كسجل محلي، لا كمعاملة لدى منصة.
- [ ] التحقق من أن السجل والأرصدة والصفقات تبقى واضحة بوصفها محاكاة.
- [ ] تجربة المحفظة التجريبية مع تعطيل الاتصال، والتحقق من إمكانية الاستخدام دون أسعار سوق حديثة.

## أسعار السوق العامة

- [ ] عند توفر الاتصال، التحقق يدويًا من جلب بيانات الأسعار العامة أو الشموع (klines) دون إدخال مفتاح API أو بيانات حساب.
- [ ] اختبار انقطاع الاتصال أو فشل المصدر والتأكد من عدم عرض الأسعار على أنها محدثة عند تعذر تحديثها.
- [ ] التحقق من أن فشل جلب الأسعار لا يحول المحاكاة إلى تداول، ولا يمنع استعمال المحفظة التجريبية المحلية.

## الاستراتيجيات والمحاكاة

- [ ] التحقق يدويًا من الاستراتيجيات المتاحة ومدخلاتها على بيانات كافية، ومن التعامل الواضح مع نقص البيانات.
- [x] اختبارات آلية تغطي وجود الكتالوج وتوليد إشارة محدودة الدرجات لكل استراتيجية على بيانات اختبار.
- [ ] مراجعة سجلات المحاكاة والنتائج التاريخية للتأكد من أنها لا تدّعي تنفيذًا حقيقيًا.

## الخصوصية وحدود المنتج

- [x] اجتاز فحص آلي للشيفرة يمنع مسارات الحساب الموثق أو أوامر `order` الحقيقية أو تخزين/قراءة مفاتيح جديدة داخل تطبيق Android.
- [ ] تأكيد يدوي على جهاز أن واجهة الاستخدام لا تطلب مفاتيح API أو كلمات مرور أو بيانات حساب.
- [x] فحص الشيفرة يؤكد أن الجسر المحلي يستخدم طلبات GET العامة للأسعار والشموع فقط وأن الشراء والبيع محاكاة داخلية.
- [ ] مراجعة السجلات ولقطات الشاشة قبل مشاركتها وإزالة أي بيانات شخصية غير لازمة.

نجاح البناء والاختبارات الآلية لا يثبت اختبار جهاز فعلي أو توفر خدمة الأسعار على كل شبكة. لا تُعلّم أي بند يدوي كمكتمل إلا بعد تنفيذه والتحقق منه.
