# قائمة اختبار DRAK 0.3.0

## بيانات السوق

- [ ] عند الاتصال، تعرض BTCUSDT وETHUSDT وSOLUSDT سعرًا عامًا من Binance Spot، ووقت آخر تحديث وحالة الاتصال.
- [ ] يعمل زر التحديث يدويًا والتحديث الدوري كل 60 ثانية عندما تكون الصفحة ظاهرة.
- [ ] تبديل السوق والفاصل يجلب بياناته الخاصة، ولا تسمح نتيجة طلب قديم بتلويث السوق الجديد.
- [ ] الشمعة المستخدمة للتحليل مغلقة فقط (`closeTime < serverTime`) ومحاذاة UTC، مع OHLCV صالح وترتيب زمني صحيح.
- [ ] عند قطع الشبكة، أو فشل/مهلة API، أو حد Binance 429/418، تظهر رسالة وحالة مناسبة ولا يُنشأ سعر اصطناعي أو شمعة بديلة.

## المؤشرات والباكتيست

- [ ] اختيار الاستراتيجيات السبع يحدّث التحليل ويشرح الإشارة أو الانتظار دون أمر تلقائي.
- [ ] الاختبار التاريخي يجلب صفحات Binance الفعلية، ويرفض الفجوات والبيانات غير الصالحة.
- [ ] يتم ترتيب الزمن وتقسيمه 70% للتطوير و30% للتقييم؛ لا تُضبط المعلمات على التقييم.
- [ ] الدخول بعد إشارة شمعة مغلقة يكون عند افتتاح الشمعة التالية، وكذلك الخروج الإشاري؛ تظل مؤشرات كل شمعة معتمدة على الماضي فقط.
- [ ] تظهر صافي P/L، الفوز، التراجع الأقصى، عدد الصفقات، الرسوم والانزلاق بوضوح، مع تنبيه عدم ضمان الربح.

## المحاكاة والسجل

- [ ] رأس المال الافتراضي الافتراضي 11 USDT، ويمكن تغييره محليًا.
- [ ] يقبل مبلغًا عشريًا مثل 3.50 و5.00 ضمن الرصيد والسقف وحد المخاطرة؛ تُخصم رسوم الدخول والخروج والانزلاق التقديري.
- [ ] يرفض مبلغًا خارج النطاق أو دقة أكثر من منزلتين أو سعرًا قديمًا أو غير حقيقي.
- [ ] يفتح مركزًا ورقيًا واحدًا في كل مرة، مع بقاء المركز مربوطًا برمز وفاصل فتحه عند تبديل السوق.
- [ ] الإغلاق اليدوي يطلب تأكيدًا محليًا، ويضيف صافي النتيجة والرسوم والسبب للسجل.
- [ ] الوقف والهدف والتنبيه الصوتي/الاهتزاز والاحتفال اختياري، ويظهر أن المتابعة لا تعمل بالخلفية.

## الأمان والبناء

- [ ] Manifest يحتوي INTERNET وVIBRATE فقط، ويمنع cleartext وAndroid backup.
- [ ] يسمح WebView بأصول التطبيق المحلية فقط؛ `connect-src 'none'`، و`blockNetworkLoads`، ولا مفاتيح أو نقاط أوامر أو API خاص.
- [ ] بناء `gradle clean assembleDebug` وفحص `aapt dump permissions` و`apksigner verify` ينجح.
- [ ] راجع [تقرير الاختبارات](replica/test-report.md) لنتائج الاختبارات المنفذة فعليًا.

لا يوجد جهاز Android 9 أو محاكي متصل في بيئة البناء الحالية؛ يلزم تنفيذ القائمة اليدوية على جهاز فعلي قبل وصف النسخة بأنها مختبرة على Android 9.
