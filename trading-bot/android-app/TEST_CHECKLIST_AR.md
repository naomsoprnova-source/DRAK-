# قائمة اختبار DRAK ورقي

## الفتح والعرض

- [ ] يفتح التطبيق بالعربية واتجاه RTL ويظهر شارة «محاكاة محلية».
- [ ] يقرأ السعر والرسم بأنه اصطناعي، ولا يعرض رصيد منصة.
- [ ] تتكيف الواجهة مع 360×800 و390×844 ومع شاشة أوسع دون قص النصوص.

## التحليل

- [ ] تبديل BTC/ETH/SOL أو الفاصل يولد عينة محلية جديدة.
- [ ] اختيار كل واحدة من الاستراتيجيات السبع يحدّث الاختيار والوصف.
- [ ] زر التحليل يعرض الفعل والسبب، ولا ينفذ شيئًا تلقائيًا.
- [ ] تشغيل اختبار 70/30 يعرض التطوير والتقييم منفصلين بوسم «اصطناعي».

## المحاكاة والسجل

- [ ] مبلغ 1–10 USDT ورقي يفتح مركزًا ضمن الرصيد وسقف المخاطرة.
- [ ] المبلغ الصفري أو غير الرقمي أو فوق السقف يُرفض دون تغيير الحساب.
- [ ] وجود مركز يمنع فتح مركز ثانٍ.
- [ ] الإغلاق الورقي بعد التأكيد يضيف النتيجة والرسوم إلى السجل المحلي.
- [ ] إعادة تشغيل التطبيق تستعيد المحاكاة فقط.
- [ ] تغيير رأس المال يمسح السجل بعد تأكيد؛ لا يعمل أثناء وجود مركز.
- [ ] مسح البيانات يطلب تأكيدًا ويعيد الإعدادات الافتراضية.

## الأمان

- [ ] لا تظهر حقول مفتاح أو زر ربط أو وضع testnet/live.
- [ ] تأكد عبر `aapt dump permissions app/build/outputs/apk/debug/app-debug.apk` من عدم وجود INTERNET أو VIBRATE.
- [ ] شغّل اختبارات Node وPython الآلية الموثقة في `replica/test-plan.md`.
- [ ] لا تجرّب أي منصة أو حساب أو اتصال خارجي؛ التطبيق غير مصمم لذلك.
