# ملاحظات إصدار DRAK Android 0.1.0

التاريخ: 29 أكتوبر 2026

## ما تتضمنه النسخة الأولية

- واجهة عربية داكنة موجهة للجوال.
- عرض أسعار سوق عامة من Binance Spot.
- قائمة من سبع استراتيجيات فنية تعليمية قابلة للاختيار.
- اختبار تاريخي مبسط على الشموع المحمّلة.
- وضع اختبار قبل التداول الحقيقي.
- إعداد اتصال Binance Spot API، وقراءة الأرصدة وإرسال أوامر Spot عند تفعيل المستخدم للتداول الحقيقي.
- مؤثرات صوتية قابلة للتفعيل والتعطيل، واحتفال قصاصات ملونة عند بعض النتائج الإيجابية.
- حماية محلية لمفاتيح API باستخدام Android Keystore وAES-GCM وفق المصدر الحالي.

## حالة التحقق

- نجح بناء نسخة APK التجريبية عبر GitHub Actions.
- لم يكتمل اختبار يدوي شامل على أجهزة أندرويد مختلفة.
- لا توجد شهادة بأن التداول الحقيقي أو كل أنواع الأوامر اختُبرت على حساب فعلي.
- لا توجد وعود بربحية أي استراتيجية.
- التشغيل الآلي ليس خدمة مستمرة بالخلفية؛ يلزم بقاء التطبيق مفتوحًا وفق حدود النسخة الحالية.

## قبل أي استخدام مالي

ابدأ بـ Spot Testnet، واختبر الاتصال وقراءة الرصيد وحالات فشل الشبكة ورفض الأوامر. لا تفعّل صلاحية السحب لمفتاح API، ولا تحفظ المفاتيح في GitHub أو تشاركها في المحادثات. لا تستخدم أموالًا حقيقية قبل مراجعة المصدر وإكمال قائمة الاختبارات اليدوية.
