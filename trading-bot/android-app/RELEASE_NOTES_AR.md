# ملاحظات الإصدار — DRAK ورقي 0.2.0

## تغييرات الواجهة والمحاكاة

- إعادة بناء الواجهة العربية بخمس شاشات: الملخص، التحليل، المحاكاة، السجل، والإعدادات.
- استبدال أسعار الشبكة بشموع حتمية اصطناعية، مع وسم واضح أن القيم ليست أسعارًا حقيقية.
- فصل المحرك إلى ملف مستقل، وإضافة تحليل للاستراتيجيات السبع وحساب محفظة ورقية محلية ورسوم افتراضية.
- إضافة اختبار اصطناعي 70/30 مع عرض منفصل لجزء التقييم وتحذير من تفسير النتيجة كأداء متوقع.
- إزالة إذن الإنترنت وجسر JavaScript وكل مسارات الحساب والأوامر الحقيقية.
- عند أول تشغيل بعد الترقية، إزالة سجل الواجهة القديم `drak_ui_v1` ومحاولة حذف بيانات API المشفرة القديمة ومفتاحها الاسمي من Android Keystore.
- تقييد سير GitHub Actions بصلاحية قراءة فقط؛ لا ينفذ أي `git push` تلقائي.

## التحقق

اختبارات المحرك واختبارات حدود المحاكاة والأذونات جزء من الشيفرة. بناء APK النهائي ونتيجة الفحص على جهاز حقيقي تُسجل في `PROJECT_STATUS_AR.md` بعد اكتمالها. بناء debug ليس إصدارًا نشرًا موقّعًا.
