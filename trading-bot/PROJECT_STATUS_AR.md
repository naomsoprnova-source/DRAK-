# حالة مشروع DRAK Binance Bot

آخر تحديث: 2026-10-29

## ما تم التحقق منه
- حزمة الإصدار 0.2.0 موجودة كملف ZIP مستقل في بيئة العمل.
- اجتازت الاختبارات البرمجية 8 اختبارات.
- تعذّر الاتصال بواجهة Binance من بيئة التنفيذ بسبب مشكلة في حل اسم النطاق.
- لم تكتمل تجربة BTCUSDT التاريخية لمدة 90 يومًا.
- لا توجد أرقام موثقة لصافي الربح أو أقصى تراجع حتى الآن.

## ملاحظة حول النشر
هذا الملف يوثق مشروع البوت داخل مستودع DRAK. لا يعني وجود هذا التوثيق أن ملفات المصدر الكاملة أو ملف ZIP الثنائي قد رُفعت إلى GitHub. يجب التأكد من وجود ملفات المصدر الفعلية قبل اعتبار النشر مكتملًا.

## قواعد السلامة
- لا تضع مفاتيح API أو كلمات المرور أو ملفات البيئة الحقيقية في المستودع.
- استخدم مفاتيح قراءة فقط عند الحاجة، ولا تفعّل صلاحية التداول.
- لا تستخدم التداول الحقيقي قبل اختبار تاريخي قابل للتكرار ومحاكاة ورقية.
