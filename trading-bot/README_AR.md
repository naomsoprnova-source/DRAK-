# دليل DRAK Binance Spot Bot — الإصدار 0.3.0

## ما هذه النسخة؟

هذه **نسخة تجريبية للمحاكاة فقط** بُنيت انطلاقًا من المواصفات المتاحة: Binance Spot، رأس مال افتراضي 11 USDT، شموع 15 دقيقة مع فلتر ساعة، مؤشرات EMA وRSI وMACD وATR والحجم، واختبار زمني 70/30. أضيفت بوابة مخاطر للمداخل الافتراضية. منطق الدخول والخروج التفصيلي لم يكن محددًا بالكامل؛ لذلك يعتمد هذا الإصدار الافتراضات المعلنة أدناه، ولا يدّعي أنه يستعيد استراتيجية سابقة.

البرنامج ينفّذ تحليلًا واختبارًا تاريخيًا ورقيًا فقط. يتصل بنقاط Binance العامة للقراءة، ولا يطلب مفتاح API أو بيانات حساب، ولا يحتوي على كود إرسال/تعديل أوامر، ولا يستخدم التداول الحقيقي.

تقتصر الاتصالات على `GET` إلى `https://data-api.binance.vision`، وتُرفض المضيفات الأخرى والتحويلات الشبكية. يتحقق البرنامج من رمز الزوج قبل استخدامه في اسم التقرير، ويرفض إعدادات المؤشرات غير الصحيحة وCSV الذي لا تطابق شموعه محاذاة UTC ووقت إغلاق 15 دقيقة. ملفات `.env` و`.env.*` متجاهلة في Git، مع السماح بقالب `.env.example`.

## التثبيت والتشغيل

يتطلب Python 3.10 أو أحدث واتصالًا بالإنترنت لجلب البيانات.

```bash
python -m venv .venv
# Linux/macOS:
source .venv/bin/activate
# Windows PowerShell:
# .venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m pytest -q
python main.py backtest --symbol BTCUSDT --days 90 --save-data data/BTCUSDT_15m_90d.csv
```

يسترجع الأمر 90 يومًا للقياس و21 يومًا قبلها لتهيئة المؤشرات، ويستبعد الشمعة الحالية غير المكتملة. يحفظ CSV قابلًا لإعادة التشغيل وتقريري Markdown وJSON في `reports/`. لإعادة الاختبار دون اتصال:

```bash
python main.py backtest --symbol BTCUSDT --days 90 --data-csv data/BTCUSDT_15m_90d.csv
```

يمكن ضبط رأس المال والرسوم والانزلاق ونسبة المخاطرة وحدّ المركز وعدد الدخولات اليومي والحد الأدنى للقيمة الاسمية ونسبة تقسيم البيانات بواسطة الخيارات `--capital` و`--fee-rate` و`--slippage-rate` و`--risk-pct` و`--max-position-pct` و`--max-trades-per-day` و`--min-notional` و`--train-fraction`. استخدم `python main.py --help` لعرضها. في التشغيل المتصل، يحاول البرنامج قراءة مرشح الحد الأدنى الحالي للزوج من `exchangeInfo` العام؛ وإذا لم يتوفر يستخدم 5 USDT ويذكر ذلك في التقرير. هذا الحد الحالي لا يعيد إنشاء قواعد Binance التاريخية.

## افتراضات الإشارة والمحاكاة

- دخول شراء عند افتتاح الشمعة التالية بعد تقاطع EMA 9 فوق EMA 21 على إطار 15 دقيقة.
- تأكيد الزخم: RSI 14 بين 50 و70، وMACD histogram موجب، وحجم الشمعة لا يقل عن متوسط حجم 20 شمعة، وإغلاق الشمعة فوق EMA 21.
- فلتر الاتجاه: آخر شمعة ساعة مكتملة فقط؛ إغلاقها فوق EMA 50 على الساعة، وEMA 20 أعلى EMA 50. يجري تجميع الساعة من أربع شموع 15m مكتملة، ولا تُقرأ ساعة لم تكتمل.
- وقف الخسارة 1.5 ATR والهدف 2R. المخاطرة المحسوبة لكل صفقة لا تتجاوز 1% من رصيد الجزء بعد تقدير الرسوم والانزلاق عند الوقف؛ كما لا تتجاوز قيمة المركز الواحد 50% من الرصيد افتراضيًا، ولا يسمح بأكثر من 4 دخولات في يوم UTC. يمكن تعديل الحدين بـ`--max-position-pct` و`--max-trades-per-day`. تتضمن التقارير عدد محاولات الدخول المحجوبة وأسبابها. لا يرفع المحاكي حجم المركز للوصول إلى الحد الأدنى الاسمي؛ بل يحجب الدخول إذا كان الحجم المحسوب أصغر منه.
- الرسم الافتراضي 0.10% والانزلاق السعري 0.05% لكل جهة، دون خصومات VIP. هذه افتراضات وليست بيانات حساب المستخدم.
- إذا مسّت شمعة واحدة الوقف والهدف معًا، يفترض المحرك حدوث الوقف أولًا. يحسب الخروج عند نهاية الفترة إجباريًا، ويحسب أقصى التراجع من الرصيد المقوّم لكل شمعة بعد الرسوم والانزلاق الافتراضيين.
- وقت الخروج المسجل عند لمس الوقف أو الهدف داخل الشمعة هو وقت إغلاق شمعة 15m؛ لا تحدد بيانات OHLC وقت اللمس الفعلي.
- تُقسّم نافذة القياس بالتسلسل الزمني إلى 70% أولى و30% لاحقة. يبدأ كل جزء منفصلًا برصيد افتراضي 11 USDT، وتُستخدم البيانات السابقة فقط لتهيئة المؤشرات. لا توجد عملية بحث عن أفضل معلمات على جزء الاختبار.

هذه المحاكاة على OHLC لا تمثل عمق السوق أو التنفيذ الجزئي أو تغير رسوم الحساب أو كل أشكال الانزلاق والفجوات. المقارنة مع الشراء والاحتفاظ مرجع وصفي فقط. لا تثبت النتائج الربحية المستقبلية أو صلاحية استخدام أموال حقيقية.

## ملفات المشروع

- `main.py`: واجهة التشغيل الورقي.
- `drakbot/api.py`: قراءة بيانات Spot العامة وCSV فقط.
- `drakbot/indicators.py`: EMA وRSI وMACD وATR وSMA.
- `drakbot/strategy.py`: شروط الإشارة وفلتر الساعة المكتملة.
- `drakbot/backtest.py`: المحاكاة والرسوم والانزلاق والإحصاءات.
- `drakbot/risk.py`: حساب حجم المركز والتحقق الورقي من سقف المخاطرة والرصيد والحد الأدنى الاسمي.
- `drakbot/config.py`: القيم الافتراضية.
- `tests/`: اختبارات المؤشرات والمحاكاة والسلامة.
- `reports/`: التقارير المحفوظة للنسخة التاريخية 0.2.0؛ ينشئ التشغيل الجديد تقاريره حسب `--report-dir`.
- `data/`: لقطة بيانات عامة قابلة لإعادة الاختبار عند حفظها.
