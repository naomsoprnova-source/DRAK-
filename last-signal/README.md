# Last Signal: Frontline

نموذج لعبة تصويب وبقاء ثلاثية الأبعاد مبني بمحرك Godot، يستهدف Android 9 (API 28) وما بعده. هذه نسخة أولية وليست لعبة بمستوى PUBG أو Call of Duty، ولا تحتوي لعباً جماعياً.

## التشغيل
افتح هذا المجلد في Godot 4.7.2 ثم شغّل المشروع. للتحقق من البناء، راجع GitHub Actions بعد كل تحديث.

## التحكم
الحركة عبر عصا الاتجاهات على الشاشة، والتصويب بالسحب في النصف الأيمن، وزر الإطلاق.

## الحالة
المصدر مرفوع. لم يتم حتى الآن التحقق من نجاح بناء APK أو اختباره على هاتف فعلي. الحد الأدنى Android 9 / API 28.
