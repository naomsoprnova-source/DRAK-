# مرصد العملات — حزمة الإصلاح

هذه مساحة مستقلة لمشروع مرصد العملات داخل مستودع DRAK-، ولا تستبدل ملفات المشروع الأصلي.

## حالة الحزمة

تم تجهيز حزمة مصدر الإصلاح محليًا، وتشمل ملفات الواجهة ومحرك الحساب والاختبارات. أبرز التحسينات الموثقة:
- احتساب كمية الشراء مع الرسوم والانزلاق وتقريب الكمية للأسفل.
- حساب العائد الصافي التقديري بعد التكاليف.
- توضيح أن سقف المخاطرة ليس ضمانًا للخسارة الفعلية.
- الفصل بين الاختبارات الاصطناعية ونتائج السوق الحية.
- التحقق من الشموع التاريخية قبل اعتماد نتائج الاختبار.
- عدم بدء الجلب التاريخي تلقائيًا عند فتح التطبيق.

## الاختبارات

الاختبار المرفق بالحزمة هو `tests/engine-smoke-test.cjs` ويُشغّل بواسطة Node.js:

```bash
node tests/engine-smoke-test.cjs
```

الشموع الاصطناعية تتحقق من سلامة الحسابات فقط، ولا تثبت ربحية الاستراتيجية. هذا المشروع تعليمي، ولا ينفذ الصفقات ولا يحتاج مفاتيح حساب التداول.

## تنبيه حول النشر

هذا الملف يعرّف بالمشروع، لكنه لا يعني أن ملفات التطبيق المصدرية أو ملف APK قد رُفعت ضمن هذا المجلد بعد.
