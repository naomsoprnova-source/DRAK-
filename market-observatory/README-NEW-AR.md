# مرصد العملات — نسخة الويب الجديدة

## الملفات
- `index.html`: واجهة عربية باتجاه من اليمين إلى اليسار.
- `engine.js`: حساب المتوسطات وRSI وATR وقراءة الاتجاه.
- `app.js`: جلب شموع Binance العامة وعرض المؤشرات وحساب المخاطرة التقديري.
- `tests/engine-smoke-test.cjs`: اختبارات أساسية لمحرك الحسابات.

## التشغيل
افتح `index.html` في متصفح حديث، أو شغّل خادم ملفات محليًا. جلب بيانات Binance يحتاج اتصال إنترنت، وقد تمنعه قيود الشبكة أو المتصفح. لا يحتاج التطبيق إلى مفتاح حساب Binance.

## حدود النسخة
هذا محلل تعليمي وليس مستشارًا ماليًا. لا ينفذ صفقات ولا يضمن الأرباح. حساب الكمية تقديري ولا يراعي كل قواعد السوق أو قيود منصة التداول. لا تعتمد عليه قبل اختبارات مستقلة على بيانات تاريخية حقيقية ورسوم وانزلاق واقعيين.

## اختبار سريع
من مجلد المشروع شغّل:
```sh
node tests/engine-smoke-test.cjs
```
