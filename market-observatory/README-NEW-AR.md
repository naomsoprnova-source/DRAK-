# مرصد العملات — نسخة الويب

## ملفات المشروع
- index.html: الواجهة العربية.
- engine.js: حساب المتوسط البسيط والمتوسط الأسي وRSI وATR وقراءة الاتجاه.
- app.js: جلب شموع Binance العامة وعرض المؤشرات وحساب حجم افتراضي للمخاطرة.
- tests/engine-smoke-test.cjs: اختبارات محرك التحليل واختبار واجهة ببيانات وهمية.
- test-report.json: تقرير الفحوصات الأخيرة وحدودها.

## التشغيل
افتح index.html في متصفح حديث، أو شغّل خادم ملفات محليًا. جلب بيانات السوق يحتاج اتصالًا بالإنترنت، وقد تمنعه قيود الشبكة أو المتصفح. لا يحتاج التطبيق إلى مفتاح حساب Binance.

## الاختبار
من مجلد market-observatory شغّل:
\`\`\`sh
node tests/engine-smoke-test.cjs
node --check engine.js
node --check app.js
\`\`\`
الاختبارات تستخدم بيانات اصطناعية واستجابة شبكة وهمية لاختبار الحسابات وعرض النتائج؛ هذا لا يثبت نجاح الاتصال المباشر بـ Binance.

## حدود النسخة
- RSI وATR يستخدمان أسلوب التنعيم المنسوب إلى Wilder.
- قراءة الاتجاه تتطلب 50 شمعة صالحة على الأقل، وتستخدم SMA20 وSMA50 وEMA20.
- حساب حجم الصفقة تقريبي لسيناريو شراء فقط، ويقيّد القيمة المقدرة برأس المال ويحتسب تقديرًا لرسوم الدخول والخروج.
- لا يتحقق التطبيق من دقة الكمية أو الحد الأدنى للطلب أو تحرك السعر أثناء التنفيذ أو فارق السعر والانزلاق أو فئة رسوم حسابك.
- لا توجد أدلة على ربحية الاستراتيجية أو اختبار تاريخي على بيانات سوق حقيقية داخل هذه النسخة.

هذه أداة تحليل تعليمية وليست نصيحة مالية؛ لا تنفذ صفقات ولا تضمن الأرباح.
