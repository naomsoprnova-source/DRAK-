# مواصفات: مرصد العملات DRAK Paper 0.3.0

## الهدف
إنشاء تطبيق Android فعلي للتدريب والتحليل التاريخي فقط، يعمل على Android 9 فما بعده، بواجهة عربية كاملة RTL، ويجلب شموع Binance Spot العامة فقط. لا يطلب التطبيق مفاتيح أو أسراراً ولا يتصل بواجهات التداول ولا يرسل أوامر. المستودع الحالي يتضمن تطبيقاً قديماً منفصلاً يسمح بمفاتيح وأوامر حقيقية؛ لن يُستخدم أو يُعدّل ضمن هذا التطبيق.

## التقنية والحدود
- Android Gradle Plugin 8.7.3، Gradle 8.9، Java 17، compileSdk 35، `applicationId com.ans.marketobservatory`, `minSdk 23`, `versionName 0.3.0`.
- واجهة HTML/CSS/JavaScript محلية داخل Android WebView، باتجاه RTL، وواجهة جسر Java واحدة مسموح بها لطلبات HTTPS GET إلى مسار Binance العام `/api/v3/klines` فقط.
- الأزواج: BTCUSDT وETHUSDT وSOLUSDT. الأطر الزمنية: 15m و1h و4h و1d.
- الإعدادات الافتراضية: رأس مال 11 USDT، الحد الأقصى لقيمة المركز 5 USDT، رسوم 0.1% لكل جهة، وانزلاق تقديري 0.05%. محاكاة طويلة فقط، مع كميات عشرية ورسوم دخول/خروج.
- كل الشموع المدخلة مكتملة فقط (`closeTime < now`). الاختبار التاريخي يعمل على رد Binance الفعلي المسترجع عند طلب المستخدم، ويعرض عدد الصفقات والنتيجة الصافية والرسوم. بيانات fixtures للاختبارات معزولة تحت `tests/`.
- السجل والمحفظة الورقية محليان على الجهاز. الصوت والاحتفالات اختياريان ومعطلان افتراضياً.
- لا يوجد ضمان ربح أو توصية استثمارية. لا يُسمح بإضافة مفاتيح، تخزين أسرار، مصادقة Binance، طلبات POST/PUT/DELETE، أو endpoints أوامر.

## الأوامر
من `market-observatory/android/`:
- الاختبارات: `node --test tests/*.test.cjs`
- فحص تركيب JavaScript: `node --check app/src/main/assets/engine.js && node --check app/src/main/assets/app.js && node --check app/src/main/assets/data.js`
- البناء: `./gradlew --no-daemon assembleDebug`
- فحص APK: `aapt dump badging app/build/outputs/apk/debug/app-debug.apk` و`apksigner verify --verbose --print-certs app/build/outputs/apk/debug/app-debug.apk`.

## بنية المشروع
- `app/src/main/java/com/ans/marketobservatory/`: Activity وجسر Binance المقيد بـ GET عام.
- `app/src/main/assets/`: الواجهة المحلية ومحرك الورق ومحلل بيانات الشموع.
- `app/src/main/res/`: اسم التطبيق والسمات والأيقونات.
- `tests/`: اختبارات Node منفصلة ببيانات اصطناعية.
- `docs/` أو `README-AR.md`: تعليمات المصدر والبناء والتثبيت وحدود المنتج.

## أسلوب الكود
JavaScript بسيط قابل للاختبار في Node دون اعتماديات؛ واجهات عامة واضحة، تحقق صارم من المدخلات، وإرجاع كائنات بيانات بدلاً من تعديل عالمي غير مقصود. مثال:
```js
function parseKlines(rows, nowMs) {
  if (!Array.isArray(rows)) throw new TypeError("استجابة الشموع غير صالحة");
  return rows.map(toCandle).filter((candle) => candle.closeTime < nowMs);
}
```
Java: Activity مسؤولة عن دورة حياة WebView فقط؛ الجسر يقبل قائمة رموز وأطر زمنية معروفة ومساراً ثابتاً ولا يقبل URL أو method من JavaScript.

## استراتيجية الاختبار
- اختبارات وحدات لمحلل بيانات Binance (الشمعة المفتوحة، الصفوف المشوهة، الأزمنة والحدود)، مؤشرات المحرك وإشارات الاستراتيجيات وحالات عدم كفاية البيانات.
- اختبارات محاكاة وحدود رأس المال والرسوم والانزلاق والكميات العشرية، ومنع المركز المكرر أو تجاوز 5 USDT.
- اختبار تاريخي اصطناعي deterministic مع عزل fixtures عن الكود المنتج.
- اختبار ساكن يمنع endpoint تداول أو حقول مفاتيح/أسرار أو بناءً غير آمن للـ WebView.
- بناء APK ثم التحقق من package id وminSdk والتوقيع وبصمة SHA-256. لا يُعلن تثبيت أو تشغيل على جهاز إلا إذا توفرت بيئة Android فعلية لذلك.

## الحدود
- دائماً: التداول الورقي المحلي حصراً؛ بيانات سوق عامة؛ رفض الشموع المفتوحة؛ توثيق الرسوم والانزلاق؛ المحافظة على الملفات غير المتعلقة؛ تشغيل الاختبارات والبناء قبل النشر.
- يُتطلب قرار منفصل قبل: إضافة تسجيل دخول أو backend أو مفتاح API أو أي اتصال تداول، أو توسيع التطبيق إلى أصل أو endpoint آخر.
- ممنوع: إرسال أوامر تداول حقيقية؛ طلب أو حفظ مفاتيح؛ استيراد كود التشغيل الحقيقي القديم؛ ادعاء ربحية؛ وضع بيانات اختبار صناعية كمصدر لاختبار تاريخي؛ إصدار APK غير مفحوص.

## معايير النجاح
1. مشروع Android قابل للبناء باسم «مرصد العملات DRAK Paper 0.3.0» وبالمعرّف `com.ans.marketobservatory` و`minSdk 23`.
2. واجهات RTL تشمل لوحة رئيسية وتحليل ومحاكاة واختباراً تاريخياً وسجل صفقات وإعدادات.
3. بيانات Binance عامة للأزواج الثلاثة فقط؛ لا شموع مفتوحة أو APIs خاصة.
4. 3 استراتيجيات على الأقل وشرح دخول/هدف/وقف، ورسوم وانزلاق محسوبان ومعلنان.
5. محفظة محلية تبدأ بـ11 USDT وسقف مركز 5 USDT وإمكانية تعديلهما وكميات عشرية.
6. صوت واحتفالات معطلان افتراضياً وقابلان للإيقاف/التفعيل من الإعدادات.
7. اختبارات آلية ناجحة، وبناء APK debug موقّع يمكن فحص بياناته وبصمته.
8. فرع GitHub منفصل وإصدار واضح يضم المصدر وAPK وملف SHA-256، إذا كانت قناة GitHub المخولة متاحة.

## افتراضات معلنة
- صفحة التطبيق الجديدة ستُضاف تحت `market-observatory/android/` ولن تحل محل تطبيقات أو صفحات أخرى في المستودع.
- لا يتوفر افتراضياً محاكي Android داخل الحاوية؛ سيُفحص ذلك ويُذكر بدقة. بناء APK والتحقق البنيوي يمكنان دون محاكي.
- لا تُستخدم بيانات Binance الحية داخل اختبارات الوحدات؛ اختبارها منفصل وقابل للإعادة على بيانات اصطناعية، فيما يبقى backtest داخل التطبيق معتمداً على رد السوق الحقيقي الذي يجلبه المستخدم.
