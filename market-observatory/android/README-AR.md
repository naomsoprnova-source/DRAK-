# مرصد العملات DRAK Paper 0.3.0

تطبيق Android عربي للتدريب على التحليل والمحاكاة الورقية. المشروع هنا مستقل عن بقية أدوات المستودع، ولا يستبدل ملفات تطبيقات أو صفحات أخرى.

## حدود الأمان

- قراءة فقط من بيانات Binance Spot العامة عبر `GET /api/v3/klines`، دون تسجيل دخول أو مفتاح API.
- الرموز المدعومة في هذه النسخة: BTCUSDT وETHUSDT وSOLUSDT، والأطر: 15m و1h و4h و1d.
- يرفض التطبيق الشمعة التي لم يمر وقت إغلاقها. واجهة WebView لا تجري اتصالات شبكة مباشرة؛ جسر Android يسمح فقط بمسار الشموع العامة الثابت.
- الشراء والإغلاق افتراضيان ومحليان على الجهاز. لا توجد واجهات تداول أو أوامر حقيقية.
- رأس المال الافتراضي 11 USDT، وحد المركز 5 USDT، مع رسوم افتراضية 0.1% وانزلاق تقديري 0.05% لكل جهة. هذه قيم قابلة للتعديل.
- الاستراتيجيات وصفية وتعليمية، وليست توصية مالية ولا تدعي الربح أو الضمان.

## المتطلبات والبناء

يتطلب البناء JDK 17 أو أحدثاً، وAndroid SDK Platform 35 وBuild Tools 35.0.0. من مجلد هذا المشروع:

```bash
./gradlew --no-daemon assembleDebug
```

ملف الاختبار الناتج:

```text
app/build/outputs/apk/debug/app-debug.apk
```

التحقق من بيانات الحزمة والتوقيع والبصمة:

```bash
aapt dump badging app/build/outputs/apk/debug/app-debug.apk
apksigner verify --verbose --print-certs app/build/outputs/apk/debug/app-debug.apk
sha256sum app/build/outputs/apk/debug/app-debug.apk
```

## الاختبارات

```bash
node --test tests/*.test.cjs
node --check app/src/main/assets/data.js
node --check app/src/main/assets/engine.js
node --check app/src/main/assets/app.js
```

بيانات `tests/fixtures/` اصطناعية ومخصصة للاختبارات فقط؛ لا تستخدمها الواجهة ولا نتائج الاختبار التاريخي. عند الضغط على «جلب البيانات وتشغيل الاختبار»، يجلب التطبيق شموع السوق من Binance، يستبعد غير المكتملة، ويفترض تنفيذ الإشارة عند افتتاح الشمعة التالية. عند ملامسة الوقف والهدف في الشمعة نفسها، يعامل الوقف كحالة أولى تحفظياً. النتائج والرسوم المعلنة لا تثبت أداءً مستقبلياً.

## الاستخدام

اختر زوجاً وإطاراً زمنياً واستراتيجية، ثم اطلب الجلب يدوياً. تعرض شاشة التحليل مستوى دخول/هدف/وقف تقديرياً وحجم مركز ورسوم وانزلاق. المحفظة والسجل والإعدادات محلية، والصوت والاحتفال معطلان افتراضياً ويمكن تشغيلهما أو إيقافهما. لا يلزم حساب Binance.
