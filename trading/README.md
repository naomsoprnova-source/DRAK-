# مرصد العملات — تحليل فني تعليمي

واجهة عربية خفيفة للمتصفح، مصممة للتجربة على الهاتف باستخدام بيانات السوق العامة من Binance.

## التشغيل
افتح `trading/index.html` أو استضف مجلد `trading` كصفحة ثابتة. يحتاج الاتصال بالإنترنت لجلب الشموع المكتملة. مثال الزوج: BTCUSDT.

## الوظائف الحالية
- EMA 9/21/50 وRSI 14 وATR 14.
- MACD 12/26/9، وADX بتنعيم Wilder، وSuperTrend، وOBV، وStochastic، وBollinger Bands، وParabolic SAR.
- توافق قواعد معلن من 7 نقاط؛ الدرجة ليست احتمال ربح.
- فحص متعدد الأطر: 15m و1h و4h و1d و1w.
- تقدير وقف و3 أهداف، وحجم شراء فوري وفق ميزانية المخاطرة والتكاليف المفترضة.
- اختبار تاريخي للشراء الفوري فقط، دخول عند افتتاح الشمعة التالية، وقف 1.5 ATR وهدف 2R، مع تكاليف لكل جهة.
- اختبار زمني خارج العينة لآخر 30% ومقارنته بالشراء والاحتفاظ بعد التكلفة.
- تقرير نصي قابل للنسخ؛ لا يحتاج مفاتيح API ولا يخزن إعدادات المستخدم.

## حدود الاختبار
الاختبار تعليمي ولا يثبت ربحية استراتيجية ولا يتنبأ بالسوق. يستخدم شموع OHLC وتكاليف افتراضية؛ لا يحاكي بدقة السيولة أو التنفيذ الجزئي أو التمويل أو جميع الفجوات. التراجع المعلن محسوب من أرصدة الصفقات المغلقة، وليس كل التراجع غير المحقق داخل الصفقة. عينة 150–1,000 شمعة وعدد محدود من الصفقات لا يكفيان لإثبات أفضلية. البيع المحتمل لا يدخل اختبار الشراء الفوري ولا يعني أن البيع على المكشوف متاح.

لا توجد أوزان GGUF مرفقة ولا اتصال بمشغل نموذج محلي. لا ينفذ التطبيق صفقات، ولا يطلب بيانات دخول أو مفاتيح API.
