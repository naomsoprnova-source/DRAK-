# الصوت العربي

لكل نداء مهم ترجمة عربية تظهر داخل اللعبة سواء وُجد ملف صوت أم لا. تُحمّل اللعبة ملفات WAV اختيارية من هذا المجلد بالمعرّفات التالية: `commander_opening`, `reinforcements`, `defend_base`, `victory`, `defeat`. إذا غاب الملف تبقى الترجمة والنص البديل ظاهرين، ولا يُشغّل صوت تجريبي.

لم يُرفق في هذه النسخة ملف أداء صوتي نهائي؛ تعذّر توليد الملفات الصوتية في بيئة البناء. قبل إصدار صوتي نهائي، أضف تسجيلات أصلية مرخّصة بهذه الأسماء، واحتفظ بتراخيصها ومصدرها في هذا المجلد.
